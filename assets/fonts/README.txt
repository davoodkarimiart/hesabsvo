Font binaries are not bundled.

Preferred method in v0.4.1: Settings -> Fonts -> upload your own licensed files.
They are stored here automatically.

Accepted deployment filenames:
- vazirmatn-400.woff2
- vazirmatn-700.woff2
- Iranian-Sans.ttf (Iranian Sans.ttf is also recognized as an existing manual file)

The same hosted files are used by desktop, mobile and Print/PDF.
