# اصلاحیه مشتری 0.6.53-p1 (۲۵ اکتبر ۲۰۲۶)

## دامنه تغییرات
- نمایش پیام کوتاه و غیرمسدودکننده پس از کپی موفق تصویر به‌جای کادر «باشه» در صفحه‌های گزارش خلاصه، گزارش تجمعی، رسید ترانسفر و تصویر جدول و مشتری.
- تاریخ **پیش‌فرض** ورودی گزارش تازه: روز قبل با محاسبه تقویم شمسی روی سرور.
- تاریخ **پیش‌فرض** پایان بازه ترانسفر تازه: روز قبل؛ ابتدای بازه هفت‌روزه نسبت به همان تاریخ محاسبه می‌شود.
- تاریخ‌های موجود و ثبت‌شده و تاریخ انتخاب‌شده در فرم ویرایش تغییر نمی‌کنند.

## استقرار
1. از سایت مشتری بکاپ دیتابیس و کپی فایل‌ها تهیه کنید.
2. فقط ZIP اصلاحیه هفت‌فایلی را در پوشه اصلی نسخه 0.6.53 Extract و Overwrite کنید.
3. کش مرورگر را تازه کنید و کپی تصاویر و تاریخ‌های پیش‌فرض را بررسی کنید.
4. نیازی به نصب مجدد، Migration یا بازیابی دیتابیس نیست.
5. نسخه اصلی هنوز 0.6.53 است؛ این بسته یک patch با شناسه p1 است.

## درباره به‌روزرسانی درون‌برنامه‌ای
در این بسته هنوز هیچ نصب‌کننده آنلاین یا دانلود و اجرای خودکار کد وجود ندارد.
پیشنهاد فنی: صفحه Developer-only با بررسی فایل manifest امضاشده/هش SHA-256، فهرست تغییرات، بکاپ پیش از اجرا، دسترسی محدود، بسته امضاشده، rollback و تأیید صریح مدیر. هرگز اجرای آزاد ZIP از URL عمومی را بدون اعتبارسنجی پیاده نکنید.

## تأیید
PHP lint و node --check تغییرات اجرا شد. تست مستقیم مرورگر/سایت مشتری باید پس از نصب پچ انجام شود.
