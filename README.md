# حساب SVO / سلطان حساب — نسخه 0.6.25

**سورس کامل و پاک‌سازی‌شده برای GitHub و نصب تازه روی هاست جدید**

- کد PHP، فایل‌های UI، گزارش‌ها، ترانسفر، خروجی XLSX و صفحه نصب موجود است.
- همه مهاجرت‌های SQL موردنیاز نصب جدید، از `001` تا `014`، در `database/migrations/` نگهداری شده‌اند.
- این یک **سورس کامل** است، نه مجموعه Patchهای وابسته به نسخه‌های قبلی.
- هیچ دیتابیس، اطلاعات ورود، توکن، گزارش خصوصی، لاگ یا قفل نصب از هاست قبلی داخل بسته نیست.

## نصب تازه روی cPanel

1. هاست Apache + PHP **8.1 یا بالاتر** و ماژول‌های `pdo_mysql`, `mbstring`, `fileinfo`, `json`, `zip`, `SimpleXML` نیاز است.
2. یک **دیتابیس خالی** MySQL/MariaDB و یک کاربر دارای دسترسی ساخت/تغییر جدول بسازید. به فایل یا بکاپ دیتابیس قبلی نیاز نیست.
3. همه فایل‌های بسته را در پوشه document root سایت جدید استخراج کنید، نه خود فایل ZIP به عنوان یک فایل تکی.
4. مطمئن شوید `config/` و `storage/` قابل نوشتن‌اند و HTTPS فعال است.
5. آدرس `https://YOUR-DOMAIN/install/` را باز کنید. اتصال دیتابیس و دو کاربر اولیه را تنظیم و نصب کنید.
6. پس از نصب، `config/config.php` و `storage/installed.lock` ساخته می‌شوند؛ از آنها نسخه پشتیبان خصوصی بگیرید و مجوزها را امن نگه دارید.
7. شرکت‌ها، پنل‌ها و گزارش‌های دلخواه را از نو وارد کنید. نصب تازه اطلاعات تجاری سایت تست را منتقل نمی‌کند.

**توجه:** نصب کامل روی MySQL/MariaDB واقعی باید روی هاست مقصد آزمایش شود. بررسی فایل‌ها و PHP به معنای تضمین نصب روی هر نسخه سرور نیست.
