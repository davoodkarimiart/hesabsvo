## 🚀 نصب تازه، بدون ترمینال

1. در cPanel دامنه‌ای با PHP **8.1+**، Apache و MySQL/MariaDB آماده کنید.
2. یک دیتابیس **خالی** و کاربر اختصاصی بسازید.
3. ZIP نصبی انتشار را در پوشه اصلی سایت Extract کنید.
4. آدرس `https://YOUR-DOMAIN/install/` را باز و مراحل را تکمیل کنید.
5. ورود Admin و Developer، محافظت از `storage/` و `config/`، گزارش مالی و بکاپ را بررسی کنید.

**هرگز بسته نصب تازه را روی سایتی که اطلاعات واقعی دارد Extract نکنید.**

## 🔌 اتصال MCP

پس از نصب، آدرس اتصال به شکل زیر است:

```text
https://YOUR-DOMAIN/mcp.php
```

دامنه باید از تنظیمات همان نصب خوانده شود. به هیچ دامنه قدیمی در سورس وابستگی نداشته باشد.
