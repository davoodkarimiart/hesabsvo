# حساب SVO / سلطان حساب — سورس یکپارچه v0.6.30

**این ZIP شامل سورس اجرایی کامل است، نه پچ هاست.** از سورس GitHub v0.6.25 و پچ‌های تأییدشده به‌ترتیب v0.6.26، v0.6.27، v0.6.28، v0.6.29 (با اینستالر امن نصب تازه) و v0.6.30 یکپارچه شده است.

- مرجع سورس اجرایی: https://github.com/davoodkarimiart/hesabsvo
- مرجع نقشه راه و فازها: https://github.com/davoodkarimiart/soltanhesab
- آخرین ورژن این بسته: `0.6.30`
- محیط فعلی: هاست تست. برای هاست جدید باید نصب آزمایشی کامل روی MySQL/MariaDB واقعی انجام شود. وجود سورس به معنی موفقیت نصب عملی نیست.

## محتویات

PHP 8.1+، JS/CSS و تصاویر، حسابداری و مشتری‌ها، گزارش روزانه/تجمعی/ریز، اکسل XLSX، ترانسفر و رسید، حذف و بازیابی شرکت‌ها، امنیت ورود و تنظیمات تب‌بندی‌شده، اینستالر مرورگری، migrationهای `001` تا `016`، و تست‌های موجود پروژه.

**هیچ دیتابیس قدیمی لازم نیست، ولی برای کارکرد اپلیکیشن یک دیتابیس خالی MySQL/MariaDB لازم است.** نصب تازه از `/install/` انجام می‌شود. `config/config.php`، `storage/installed.lock`، گزارش و لاگ مشتری‌ها نباید در Git وجود داشته باشند.

### امنیت

- تغییر رمز و کدهای یک‌بارمصرف بازیابی، کنترل تعداد تلاش ورود و حفاظت از نشست‌ها اضافه شده است.
- Cloudflare Turnstile **اختیاری و پیش‌فرض غیرفعال** است. اگر قصد فعال‌سازی دارید، هر دو مقدار `security.turnstile_site_key` و `security.turnstile_secret_key` را به‌طور خصوصی در `config/config.php` تنظیم کنید؛ **secret key را هرگز commit نکنید**. اعتبارسنجی سمت سرور در کد موجود است.
- برای نصب تازه، اینستالر امن نسخه ۰.۶.۲۹ داخل همین بسته است و رمز اولیه حداقل ۱۲ بایت می‌خواهد. *Livefix* نسخه ۰.۶.۲۹ فقط برای سایت تست استفاده شده بود و عمداً نسخه قدیمیِ اینستالر را وارد این بسته نکرده‌ایم.
