# سلطان حساب — نسخهٔ 0.6.5

این مخزن سورس پاک برنامهٔ حسابداری سلطان حساب است. این نسخهٔ یکپارچه پچ‌های 0.5.7 تا 0.6.1 و 0.6.3 تا 0.6.5 را از روی مبنای 0.5.6 بازسازی می‌کند. پچ ناموفق 0.6.2 در این سورس وارد نشده است.

## تغییرات

- گزارش تجمعی چند گزارش با انتخاب یک یا چند تاریخ؛ خروجی پیش‌نمایش، تصویر، چاپ/PDF و Excel.
- جمع دریافتی و پرداختی به‌صورت ناخالص و جداگانه، بدون تهاتر متقاطع میان آن‌ها.
- کنترل تطبیق ماندهٔ دلاری با نتیجهٔ سبز/قرمز/زرد و نمایش مبلغ یا اختلاف.
- اصلاح انتخاب و پیش‌نمایش گزارش‌ها، از جمله انتخاب چندتایی و حالت موبایل.
- ورودی تاریخ تک‌روزه یا بازه‌ای و اصلاح عرض فیلدهای «از تاریخ» و «تا تاریخ» در دسکتاپ.
- نسخه‌گذاری منابع UI و به‌روزرسانی چرخهٔ cache برنامهٔ PWA.
- تغییری در schema پایگاه داده لازم نیست.

## راه‌اندازی

1. `config/config.example.php` را به `config/config.php` کپی کنید و اطلاعات پایگاه داده و secret یکتای برنامه را تنظیم کنید.
2. پوشه‌های runtime را برای PHP قابل‌نوشتن نگه دارید؛ فایل‌های آن‌ها در Git نگهداری نمی‌شوند.
3. برای ارتقا، ابتدا پشتیبان بگیرید و مراحل `UPGRADE.md` را اجرا کنید.
4. تست فرمول‌ها: `php tests/phase3_formula_smoke.php`؛ بررسی انتشار: `php verify_release.php`.

فایل تنظیمات واقعی، `.env`، `.user.ini` هاست، لاگ‌ها، پایگاه داده، گزارش‌های مشتری و نسخه‌های پشتیبان را commit نکنید.
