# حساب SVO / سلطان حساب — سورس ۰٫۶٫۵۳

این مخزن سورس اجرایی سلطان حساب است. مخزن [soltanhesab](https://github.com/davoodkarimiart/soltanhesab) فقط برای نقشه‌راه و سابقهٔ تصمیم‌هاست و سورس تاریخی آن برای استقرار استفاده نمی‌شود.

## این نسخه

نسخهٔ ۰٫۶٫۵۳ شامل ماژول‌های عملیات توسعه‌دهنده و فاز ۱۱ MCP است: اتصال JSON-RPC با OAuth/PKCE و مجوزهای محدوده‌دار، ابزارهای گزارش و تشخیص، مدیریت بکاپ، اجرای زمان‌بندی‌شده از CLI و ارسال اختیاری بکاپ به تلگرام. در نصب تازه فاز ۱۲، migration شماره 017 برای ستون‌های شرکت اضافه شده است.

ابزارهای خواندن اطلاعات مالی و ابزارهای نوشتن دارای scope جدا هستند؛ scopeهای نوشتن فقط برای نقش‌های مجاز و پس از تأیید OAuth صادر می‌شوند. `admin:backup` و `admin:diagnostics` مختص توسعه‌دهنده‌اند. جزئیات وضعیت پذیرش و محدودیت‌های تست در [یادداشت انتشار](RELEASE_NOTES_FA.md) آمده است.

## نصب و ارتقا

- نصب تازه: پیش‌نیاز PHP 8.1+، Apache، MySQL/MariaDB و افزونه‌های لازم را در [راهنمای cPanel](DEPLOY_CPANEL.md) ببینید.
- سورس این مخزن handoff نصب تازه است، نه پچ مستقیم هاست زنده. برای ارتقای سایت فعال، ابتدا بکاپ بگیرید و فقط فایل‌های نسخه‌مند را با روش کنترل‌شدهٔ همان محیط جایگزین کنید.
- `config/config.php`، `storage/` runtime، tokenهای OAuth، تنظیم تلگرام، لاگ‌ها و فایل‌های بکاپ هرگز نباید commit شوند.

## پذیرش فاز ۱۲

نصب تازه روی `behagent.ir` توسط مالک پروژه آزمایش شد؛ گزارش‌های مالی، بازیابی بکاپ، MCP و Cron همراه با ارسال تلگرام در ۲۵ اکتبر ۲۰۲۶ تأیید شدند. این آزمایش‌ها ممیزی نفوذ کامل یا تضمین امنیت جامع نیستند. [جزئیات آزمون‌ها](docs/PHASE12_ACCEPTANCE.md).
